\# Projeto Barbearia



Sistema web para gerenciamento, busca e agendamento de serviços em barbearias.



\## Sobre o projeto



O Projeto Barbearia está sendo desenvolvido como projeto acadêmico integrado, envolvendo desenvolvimento web, programação orientada a objetos e banco de dados.



O sistema permitirá que clientes encontrem barbearias, consultem serviços e horários disponíveis e realizem agendamentos.



Também haverá áreas específicas para proprietários de barbearias e barbeiros.



\## Principais funcionalidades



\- Cadastro e login de usuários

\- Busca de barbearias

\- Consulta de serviços

\- Consulta de horários disponíveis

\- Agendamento de serviços

\- Gerenciamento de barbeiros

\- Gerenciamento de serviços

\- Gerenciamento de horários

\- Promoções e combos

\- Área administrativa da barbearia

\- Agenda do barbeiro
