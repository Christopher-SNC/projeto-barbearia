# Fluxo Git da Equipe



Este documento define o fluxo de trabalho utilizado no Projeto Barbearia.



## Regra principal



Não desenvolver funcionalidades diretamente na branch `main`.



A branch `main` representa a versão principal e estável do projeto.



Cada nova tarefa deve ser desenvolvida em uma branch própria.
